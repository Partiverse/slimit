# SlimIt 竞品定位分析

> 最后更新：2026-10-01。所有数据来自各产品官网、GitHub 仓库与独立测试。

## 核心问题

磁盘清理工具市场存在一个**信任真空**：

- 用户不知道"这个文件是谁创建的"
- 工具要么只给图表（DaisyDisk），要么只给建议（CleanMyMac），都不提供**实证归因**
- 同类工具已经把"AI"重新定义成不可审计的黑箱，并以此为卖点

SlimIt 的差异化：**唯一能实证告诉你「这个文件是谁创建的」的磁盘清理工具。**

## 差异化定位

### SlimIt 的独特价值主张

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   「这个文件是谁创建的？」                                    │
│                                                             │
│   其他工具：                                                  │
│   - DaisyDisk/OpenDisk："这个文件夹很大"                      │
│   - DiskSage："这个路径是缓存"                                │
│   - CleanMyMac："AI 说可以删"                                 │
│                                                             │
│   SlimIt：                                                   │
│   - "这个文件由 com.apple.Safari（签名：Apple）创建"          │
│   - 证据：Endpoint Security 进程签名                          │
│   - 判断权：永远在你手里                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 为什么"AI 清理"是错误的方向

同类工具已经把"AI"重新定义成：

1. **不可审计的黑箱** — 用户无法验证 AI 的判断依据
2. **自动执行的危险** — "AI 清理"可能误删重要文件
3. **营销噱头** — 实际效果依赖路径规则，与"AI"无关

SlimIt 的反其道而行：

- **AI 只解释，规则才授权** — 执行授权唯一来源是确定性规则引擎
- **可审计的判断** — 每条规则可阅读、可挑战、可验证
- **用户保留最终决定权** — 删除永远进隔离区，14 天可恢复

## 权限诚实披露

### 为什么需要完全磁盘访问权限

macOS 的进程级归因依赖 **Endpoint Security (ES) 框架**，这是 Apple 的平台限制：

| 能力 | 需要权限 | 原因 |
|------|----------|------|
| 进程签名读取 | 完全磁盘访问 或 管理员 | ES 框架要求 |
| 快照 diff 模式 | **无** | 仅文件元数据比较 |
| 重复文件检测 | 读文件内容（仅头部 + 全量哈希） | 需要访问文件数据 |
| 隔离区操作 | 写权限（仅隔离区目录） | 移动文件到隔离区 |

**SlimIt 不会假装自己能做到它做不到的事**：

- 无 FDA 时，自动降级为"快照 diff 模式"，明确告知用户
- 不请求不必要的权限
- 不隐藏权限需求

## 竞争策略

### 短期（MVP 阶段）

1. **归因差异化** — 唯一提供进程级归因的磁盘清理工具
2. **权限诚实** — 明确告知用户需要什么权限、为什么需要
3. **开源透明** — 规则引擎、扫描器、执行器全部开源，可审计

### 中期（Windows/Linux 支持）

1. **跨平台归因** — Windows 用 USN Journal，Linux 用 fanotify
2. **规则库共享** — 跨平台规则复用，减少重复工作
3. **企业版** — 集中式审计、合规报告、API 集成

### 长期（生态建设）

1. **规则市场** — 用户贡献规则，社区审核
2. **集成生态** — 与备份工具、监控工具、CI/CD 集成
3. **AI 解释层** — 可审计的 AI 解释，非黑箱决策

## 结论

SlimIt 不是"另一个磁盘清理工具"。它是**唯一能实证告诉你「这个文件是谁创建的」的工具**。

在同类工具把"AI"重新定义成不可审计黑箱的时代，SlimIt 反其道而行——**分类完全由确定性规则引擎决定，AI 仅作解释层，永不授权删除**。

**差异化在归因：我们不猜，我们取证。**
